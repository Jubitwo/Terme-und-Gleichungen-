# Terme und Gleichungen

Interaktive Lernseite zum Umgang mit Termen, Variablen, Gleichungen sowie Ausmultiplizieren und Ausklammern. Die Übungen sind auf die Klassen 7 und 8 ausgerichtet.

## Inhalte

- Terme und Variablen verstehen und Werte einsetzen
- Gleichartige Terme zusammenfassen
- Gleichungen Schritt für Schritt lösen
- Klammern ausmultiplizieren und gemeinsame Faktoren ausklammern
- Gestufte Buch- und Übungsaufgaben

## Schnellstart

Repository herunterladen oder klonen und index.html in einem aktuellen Browser öffnen.
